# 0006. Java 25 comme version minimale

- Statut : Accepté
- Date : 2026-10-09 (rétroactif)
- Tâche : #12

## Contexte

Projet neuf, aligné sur les dernières versions de Spring (Boot 4, Cloud 2025.1).

## Options envisagées

- Java 17, minimum de Spring Boot 4 : audience maximale.
- Java 21.
- Java 25, dernière LTS.

## Décision

Java 25.

## Conséquences

- Accès aux fonctionnalités récentes du langage, outillage à jour (Checkstyle 14 requiert Java 21 au minimum).
- Les projets restés sur Java 17 ou 21 ne peuvent pas utiliser le starter.
